# math-admin

Admin dashboard for the Math-AI platform (Vietnamese elementary-school math
quizzes). React 19 + Vite + TypeScript. The backend is `math-svr` (Go).

The owner is a backend developer with little frontend experience: explain
frontend choices briefly when they are not obvious, and prefer boring,
well-documented libraries over clever ones.

## Backend contract — read before any API work

@docs/API-CONTRACT.md

The five rules that break most often:
1. Every route is `POST` with a JSON body. No path/query params.
2. The auth token goes in the body at `metadata.authorization`, never in the `Authorization` header.
3. Read `X-Auth-Token` from every response; when present it replaces the stored token.
4. HTTP is always 200 — success/failure is `mstatus` in the body (2xx = ok). Show `mmessage`, log `debug`.
5. `Content-Type` is exactly `application/json`; multipart bodies carry `metadata` as a JSON-string form field.

All HTTP goes through one API client module — components never call `fetch` directly.

How the frontend calls the API:
- `src/libs/ApiClient.ts` implements the five rules: `apiPost(path, fields)` for JSON,
  `apiPostMultipart(path, fields)` for uploads. Both return the envelope with the data
  fields flattened in, or throw `ApiError` (`mstatus`, user-facing `message`, `debug`).
- Screens use TanStack Query (`useQuery` / `useMutation`, client in `src/libs/QueryClient.ts`)
  around those functions. Failed mutations toast the server message automatically
  (opt out with `meta: { silentError: true }`); failed queries are shown inline by the screen.
- Any `401` clears the token and sends the app to `/sign-in`.
- The signed-in user is the `sessionQueryOptions` query (`src/features/auth/AuthApi.ts`, restored
  with `/auth/resume-session`). `(dashboard)/layout.tsx` is the route guard; screens below it can
  assume a user.
- Wire types live in `src/types/` (`Api.ts`, `User.ts`, `Banner.ts`, `Curriculum.ts`, `Role.ts`, `Device.ts`, `Profile.ts`, `System.ts`, `Exam.ts`) and mirror the Go DTOs.

## Folder structure

Layout adapted from [ixartz/SaaS-Boilerplate](https://github.com/ixartz/SaaS-Boilerplate) (its Next.js
folders, on a Vite SPA). Import from `src` with the `@/` alias.

```
src/
  app/                  routes — folders mirror the URL (React Router, table in app/router.tsx)
    (auth)/             "(group)" = shared layout, no URL segment: sign-in, verify-otp
    (dashboard)/        signed-in shell (sidebar + header): users, profiles, banners, curriculum/* (programs,
                        grades, semesters, schools — one shared screen), devices, permissions/* (permission
                        module: roles), exams/* (journeys → sittings, question pool, generation prompts; admin only), system/* (admin ops)
  components/           app-wide components (Logo, LocaleSwitcher)
    ui/                 shadcn/ui — generated by `npx shadcn@latest add <name>`; edit sparingly
  features/<area>/      components owned by one area (dashboard, auth, users, profiles, banners,
                        curriculum, devices, permissions, exams, system)
  hooks/                shared React hooks (UseXxx.ts)
  libs/                 setup of third-party libs + the API client (I18n.ts, ApiClient.ts)
  locales/              vi.json (source of truth, keys are type-checked) + en.json
  styles/global.css     Tailwind + NUMI theme tokens (shadcn CSS variables)
  types/                shared TS types (API DTOs, Route, I18n)
  utils/                pure helpers + AppConfig.ts
public/assets/images/   NUMI logo/mascots, copied from math-app
```

A page lives at `src/app/<group>/<path>/page.tsx` and is registered in `src/app/router.tsx`.

## Look and feel

- UI kit is **shadcn/ui**; theme colors come from the mobile app (`math-app/lib/core/theme/`) and live
  only in `src/styles/global.css`. Use the tokens (`bg-primary`, `text-muted-foreground`, `bg-success-surface`…), never raw hex in components.
- The approved design: https://claude.ai/artifact/19qE9a4k81UxzcM9nvBEX9 — build screens to match it.

## Conventions

- UI text comes from `src/locales/{vi,en}.json` via `useTranslation()` — never hard-code UI strings. Vietnamese is the default locale; code, comments, and commits are English.
- Commits follow Conventional Commits (`feat:`, `fix:`, `chore:`…) — enforced by commitlint through Lefthook, which also runs lint + type-check before each commit.
- IDs are numbers; never send an id on create.
- Destructive actions (`force-delete`, anything irreversible) need an explicit confirm dialog.
- Hiding a button is not authorization — the users/banners/curriculum routes are not admin-gated yet (see contract §5).

```bash
npm run check:types  # tsc -b
npm run lint         # oxlint
```
